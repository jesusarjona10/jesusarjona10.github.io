# jesusarjona10.github.io
AURUM · Tienda y laboratorio de hardware

Web de demostración para un negocio premium de venta y reparación de hardware en Granada: componentes, PCs, portátiles, móviles y consolas. Estética sci-fi en negro mate y oro cepillado.

Los precios, datos de contacto y el pago son ficticios.

Características
Tienda con 31 productos, filtros por categoría, precios y especificaciones.
Carrito persistente y checkout simulado con envío, IVA y número de pedido.
Seguidor de estado de reparación (código de prueba: AU-1234).
Preguntas frecuentes, contacto con formulario y enlace a Google Maps.
Diseño responsive.
Uso

Descarga el repositorio y abre index.html en el navegador. No requiere instalación.

index.html   → estructura
styles.css   → estilos
script.js    → productos, carrito y formularios

Para personalizarlo, edita la lista D (productos) y las variables PHONE y MAIL al inicio de script.js.

Limitaciones

Las imágenes son ilustraciones vectoriales y el pago es una simulación. Para uso real haría falta un backend y una pasarela de pago.

Tecnologías: HTML · CSS · JavaScript
